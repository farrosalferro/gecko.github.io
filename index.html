Abstract

Recent vision and language models (VLMs) have demonstrated remarkable success, even surpassing human performance in certain tasks. However, these models struggle with recognizing small objects in high-resolution images. To address this limitation, a previous study introduced a visual search method where VLMs iteratively search for clues to identify small target objects using fine-tuned vision modules. While this approach improves small object recognition, it incurs high inference times due to its iterative operations, extensive use of vision modules, and significant computational costs from training.

We propose a plug-and-play method that leverages pre-trained model weights without requiring external tools or additional training. This method capitalizes on the vision encoder’s inherent ability to contrast images and text, enabling it to selectively focus on image areas relevant to the queries. Consequently, this approach streamlines the process and reduces resource consumption.

Gecko Framework

Gecko is a plug-and-play framework that allows Vision Language Model (VLM) to identify small objects in high-resolution images. As shown in below figure, Gecko can be summarized as follows:

  1. Image Cropping: Images are divided into patches that match the native resolution of the vision encoder. This ensures the preservation of fine details, especially those of small objects.
  2. Keyword Extraction: We use in-context learning with a native LLM to extract the "queried object" from the provided prompt.
  3. Patch Selection: The vision encoder and its text encoder counterpart leverage contrastive ability to identify and select the most relevant patches.
  4. LLM Inference: The selected patches are then passed to the LLM to generate a response to the given prompt. We use Mantis for its ability to handle multiple images effectively.

Multi V* Bench

We adapted the Gecko framework to allow the model to find the small objects across multiple images. To test this, we curated a new benchmark called Multi V* Bench, which includes multi-image, high-resolution visual question and answer tasks with an average resolution of 1920 × 2475 pixels. The benchmark consists of four tasks, each comprising 20 samples:

  • Attribute: Identify attributes differences of an object between images. There are 43 images in total with resolution of 1920 × 2622 pixels.
  • Existence: Determine if an object exists between the images. There are 47 images in total with resolution of 1920 × 2419 pixels.
  • Counting: Count the number of objects among the images. There are 56 images in total with resolution of 1919 × 2467 pixels.
  • OCR: Extract or identify text from the images. There are 55 images in total with resolution of 1920 × 2414 pixels.
